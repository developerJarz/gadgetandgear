# Gadget & Gear BD (gadgetandgear.bd)

A premium Next.js 15 e-commerce web application for electronics, flagship smartphones, ultrabooks, audio devices, and smart tech accessories in Bangladesh.

![Gadget & Gear BD](public/favicon.svg)

## 🚀 Key Features

- **Storefront & Catalog**:
  - Interactive Visual Category Carousel & Spotlight Showcase.
  - Multi-faceted Filter System: Real-time keyword search, dual price range presets/slider, multi-brand selector, and deal tags.
  - Multiple View Modes: 4-Column Grid, 3-Column Compact Grid, and Detailed List View with specifications and 0% EMI calculation.
  - Instant Product Quick-View Modal for fast inspection and add-to-cart.
- **Cart & Checkout**:
  - Drawer slide-out cart with coupon discount engine and shipping calculation.
  - Multi-step checkout with bKash, Nagad, Rocket, SSLCommerz, and Cash on Delivery (COD).
- **Admin Dashboard**:
  - Comprehensive management panel (`/admin`) for Products, Categories, Brands, Orders, Staff, and Store Settings.
  - Multi-role role-based access control (Admin, Manager, Staff, Customer).
- **Design & Performance**:
  - Modern dark/glassmorphic responsive UI built with Tailwind CSS.
  - Fully typed with TypeScript and optimized with Next.js App Router.

## 🛠️ Technology Stack

- **Framework**: Next.js 15 (App Router, React 19)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Lucide Icons, CSS Modules
- **State Management**: React Context & Hooks
- **Database / API**: Next.js Route Handlers & Mongoose / LocalStorage store fallback

## 📦 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/developerJarz/gadgetandgear.git
   cd gadgetandgear
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
